# Ертегіден экранға

«Зерде» республикалық зерттеу жобалары конкурсына арналған білім беру сайты.
Зерттеу тақырыбы: қазақ халық ертегілері мен олардың мультфильм нұсқаларының
ұқсастықтары мен айырмашылықтары.

**Автор:** Нұрғалиұлы Мұхамед (6-сынып)
**Секция:** Қазақ тілі мен әдебиеті

## Мазмұны

- `index.html` — сайттың негізгі беті (барлық бөлімдер бір файлда)
- `css/styles.css` — дизайн жүйесі, бейімделгіш (responsive) стильдер, басып шығару режимі
- `js/data.js` — жеті ертегі деректері, салыстырмалы талдау, ұлттық құндылықтар, 12 викторина сұрағы
- `js/app.js` — викторина логикасы, ертегі терезелері, іздеу, навигация, анимациялар

## Іске қосу

Сайт — таза HTML/CSS/JavaScript, құрастыру (build) қажет емес.

**Әдіс 1:** `index.html` файлын браузерде ашыңыз (Chrome, Firefox, Edge, Safari).

**Әдіс 2 (жергілікті сервер):** жоба қалтасында:

```bash
python3 -m http.server 8000
```

сонан кейін браузерден `http://localhost:8000` мекенжайын ашыңыз.

## Бөлімдер

1. **Басты бет** — жоба таныстырылымы, жеті ертегінің шолуы
2. **Жоба туралы** — автор, мақсат, міндеттер, өзектілік, әдістер
3. **Ертегілер кітапханасы** — әр ертегі үшін толық талдау (мазмұн, салыстыру, құндылықтар, тәрбиелік мәні, автор пікірі)
4. **Салыстыру** — 5 критерий бойынша екі бағанды кестелер, басып шығаруға дайын
5. **Ұлттық құндылықтар** — 11 мәдени белгі галереясы
6. **Зерттеу нәтижелері** — қорытындылар + сауалнама нәтижелеріне арналған орын (автор толтырады)
7. **«Ертегіні таны» викторинасы** — 12 сұрақ, ұпай санау, қайта өту
8. **Практикалық материалдар** — сабақта қолдану нұсқаулары
9. **Дереккөздер** — расталған сілтемелер + автор толтыратын орындар
10. **Кері байланыс** — байланыс деректеріне арналған орын

## Ескертулер

- Сайт толықтай қазақ тілінде.
- Сауалнама сандары мен кітапхана/мультфильм сілтемелерінің бір бөлігі әдейі
  толтыруға арналған орын ретінде белгіленген — оларды автор растап қосады.
- QR-кодтар қолданылған жоқ.
- Дереккөз ретінде расталған сілтемелер ғана берілген (adebiportal.kz, kitap.kz, abay-cbs.kz).
